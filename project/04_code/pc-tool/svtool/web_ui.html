X·Y 동시 운전 — 각 축 카드의 목표 pulse·속도·가감속 값으로 두 축을 같은 제어 주기(1 ms)에 시작

한 축이라도 시작할 수 없으면 두 축 모두 시작하지 않습니다. 외부 입력: DI3(GPIO18) = 동시 START(상대), DI4(GPIO17) = 동시 STOP(감속). 동시 STOP은 안전 비상정지가 아닙니다.

보간 경로 (시작점 = 현재 위치)

원호: 끝점은 중심에서 시작점까지의 반지름 위에 있어야 합니다. 끝점 = 시작점(상대 0, 0)이면 한 바퀴.

이송
X-Y 평면 (pulse) 미리보기 실제 궤적 현재 위치 시작 끝

가로 = X, 세로 = Y(같은 축척). 휠로 확대·축소, 더블클릭으로 원래 크기. 실제 궤적은 운전 중 약 20회/초로 읽은 위치입니다.

변경 적용은 장치 RAM에만 씁니다(전원을 끄면 사라짐). 설정 저장은 표에서 고친 값을 먼저 적용한 뒤 플래시에 저장하므로 전원을 꺼도 유지됩니다. 축이 운전 중이면 일부 항목은 거부될 수 있습니다.

항목설명값범위기본값

장치가 스스로 판정한 배선 상태(wiring_status)입니다. 0.25초마다 갱신됩니다.

장치 설정(시스템, 축 파라미터, 포인트 테이블, 네트워크, 레거시 창)을 JSON 파일로 내려받습니다. 형식은 svtool backup과 같습니다.

복원은 차이 확인과 잠금 해제 절차가 있어 명령줄에서 합니다: python -m svtool restore 파일 --target IP

하드웨어 GPIO 배정

GPIO구분신호방향극성·비고커넥터
  • D-087(2026-11-04): X축 펄스 GPIO25 → GPIO22, RS-485 TX GPIO24 → GPIO14로 옮겼습니다. GPIO24·25는 칩 내장 USB Serial/JTAG 핀이라 비워 둡니다. 이전 캐리어(r2)는 GPIO25·24에 배선되어 있으므로 새 캐리어에서 바꿔야 합니다.
  • GPIO 번호는 ESP32-P4 칩 기준(3.3 V 로직)입니다. 보드 헤더의 물리 핀 위치는 보드 실크 인쇄를 확인하세요.
  • 캐리어 커넥터(J7, J13 등)의 펄스 신호는 절연·차동(AM26C31) 후 출력이므로, 3.3 V 로직 분석기는 보드 헤더의 GPIO에서 측정합니다.
  • STOP 입력은 NC 접점입니다. 배선이 끊기면 정지 상태가 됩니다(안전 측). START·예비 입력 LOW 활성은 권고값이며 보드에서 아직 확인하지 않았습니다.
  • 벤치 빌드(sdkconfig.bench, 캐리어 없는 P4 보드 시험용, D-085)에서는 STOP이 A접점입니다: 내부 풀업으로 평소 정상, GPIO19·GPIO8을 GND에 대면 해당 축 정지. 제품에는 쓰지 않습니다.
  • 값은 펌웨어 빌드 설정(menuconfig)으로 바꿀 수 있습니다. 바꾼 펌웨어에서는 이 표가 실제와 다를 수 있습니다.
