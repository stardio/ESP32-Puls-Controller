## 2. 다음 단계가 반드시 알아야 할 핵심 내용 (최대 10줄)
1. 라인업: 축 수(1축/2축, D-015) × 통신(TCP/RTU, D-034·D-051) = 4개 조합(SRS §2.1, CON-011). **(D-051) 이더넷(온보드 IP101) Modbus TCP 서버(FR-022)는 전 모델 기본**, [RTU 모델]은 여기에 RS-485 Modbus RTU 슬레이브(FR-025)를 추가한다('RTU 전용' 모델은 없음, D-054). 모델 간 미실장 차이는 RS-485부뿐(CON-013). **(D-056) [RTU 모델]에서 TCP 서버와 RTU 슬레이브는 둘 중 하나만 동작**, 선택 방법은 Q41(**G3 필수**). D-039(RTU 모델에 HMI와 PLC·PC 동시 연결은 v1 범위 밖)와 일치. 같은 축 수에서 레지스터 맵·기능 동일(FR-026, [RTU 모델] 선택 항목은 예외).
2. **v1 필수 I/O(D-044, CON-015):** 입력 START(FR-028, **엣지 판정 D-050, 펄스열 출력 시작 D-055**)·STOP(EMG)(FR-010, **펄스열 출력 정지 D-055**. 래치 여부·정지 방식(즉시/감속)은 Q38 잔여 **G3 필수**, 래치는 [가정]), 출력 서보 ON(FR-011(c) 필수, D-042). 나머지 DI·DO는 예비. [2축 모델] I/O 기능은 서보 ON·START·STOP(D-057), 8점 확장 예정(D-052, 현재 DI 4·DO 4). 축별 배정·8점 배분은 Q37 잔여, [가정] 축별 3점(입력 4·출력 2).
3. **우선순위 하향:** FR-008(원점 센서 원점복귀)·FR-009(센서 리밋)·FR-011(a)(b)(드라이브 알람·완료 입력)는 '미확정(I/O 사양 확정 시 재검토)'. 삭제하지 않았다. v1 설계·검증 대상에서 일단 빠진다. SCH-REC S-01(DI 11점 대 4점)은 v1 범위에서 해소 방향.
4. FR-021 진단 입력 상태는 사용 I/O(START·STOP(EMG)·서보 ON)로 줄였다. 원점·리밋·알람·완료는 보류.
5. **원점복귀(D-045, Q35 답변):** FR-023 (b)의 원점복귀 운전 조작은 미확정. 원점복귀 기능(원점 입력 포함)은 필요 시 추가하며 I/O 확정 때 재검토. 기본 화면·시험에서 원점복귀는 일단 뺀다. 나머지 (b)(시작·정지·JOG·알람 해제)와 (a)(c)(d)는 필수.
6. **펄스 출력 형식:** 차동만 제공(NFR-005(a) 필수, D-046). 24 V 오픈 컬렉터(NFR-005(b))는 v1 범위 밖. Pulse/Direction 확정(채널 A = 펄스, B = 방향, D-048, FR-001). CW/CCW(FR-002)는 v1 범위 밖.
7. [2축 모델] I/O 구성: 기능 서보 ON·START·STOP(D-057), 8점 확장 예정(D-052). [가정] 축별 3점 → FR-011(c) 축별 서보 ON, FR-028 축별 START, FR-010·NFR-011 축별 STOP(해당 축만 정지, 직전안의 "2축 전부 정지" 대체). 축별/공용 배정, 8점 DI·DO 배분, 회로 확장 방식, 예비 배정은 미확인(Q37 잔여). [가정]이 현재 회로(DI 4·DO 4)로 되는지 ③ 확인.
8. D-041: EtherCAT 마스터와 그 예비 이더넷 포트는 이번 범위 밖(CON-002, CON-010). Q39는 D-051로 해소(온보드 이더넷 전 모델 실장, RTU 모델 이더넷 몫 절감 없음).
9. FR-016·FR-018 경로: [RTU 모델] 보드 USB(D-037, CON-014), [TCP 모델] 이더넷(DC-09 제안). [TCP 모델] USB 병행(Q34 (a)), [RTU 모델] 이더넷 병행(Q34 (b), D-051) 미확인. D-056(HMI 통신 택일)은 PC 도구 이더넷 경로와 별개로 해석(Q41에서 확인). 화면 데이터(FR-024): 표준 지원 패널 이지뷰·M2I, 기종·기종 수는 화면 데이터 제작 시 결정(D-053, Q26 G3 필수 해제). RS-485 전용 패널 포함(D-038, D-054). Q30 종료.
10. 대표 드라이브 미쓰비시·LS·대우(D-026), 모델 미확인(Q1-잔여). 잠정 판매가는 참고(COST-006, TCP/RTU 차등 D-040, 금액 G6). 2축 실측 보류(D-030).
