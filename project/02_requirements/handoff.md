## 2. 다음 단계가 반드시 알아야 할 핵심 내용 (최대 10줄)
1. 대상: 펄스 열(Step/Dir, CW/CCW 권장) 입력형 드라이브용 컨트롤러. 라인업은 1축 모델·2축 모델 2종(D-015, FR-003, CON-011). 모델 간 차이는 §2.1에 모았고, 축 수 외 차이는 없음 [가정](Q27). 대표 드라이브 제조사 미쓰비시·LS·두산(D-009), 모델 미확인.
2. 펄스 성능: 축당 ≥ 200 kpps(D-007, NFR-001, 두 모델 공통). [2축 모델]은 2축 동시 운전에도 축당 ≥ 200 kpps(D-010·D-015, NFR-002). 펄스 누락 0(NFR-004), 지터 미확인(NFR-003). ESP32 라이브러리 문서의 2축 수치 저하(37k steps/s)는 실측이 필요한 설계 위험(CON-005, SRS §9 #9).
3. 통신: Modbus TCP 필수(D-017, FR-005). 컨트롤러는 유선 이더넷(D-019 확정)으로 Modbus TCP 서버 동작(FR-022). RTU는 필수 [가정] 유지, 병행 여부 미확인(Q23, G3). 동시 접속 수 미확인(NFR-023, Q26).
4. HMI: 5/7인치 산업용 범용 터치패널, Modbus TCP만으로 연동(CON-012). 표준 지원 메이커는 이지뷰·M2I(D-021). 기본 화면은 운전에 필요한 모든 데이터·파라미터(D-022): FR-023 (a) 상태 표시, (b) 운전 조작(시작/정지·원점복귀·JOG·알람 해제), (c) 파라미터 조회·변경, (d) 진단 표시 모두 필수. 화면 데이터는 당사가 제작해 제공(FR-024). 두 메이커의 대상 모델·기종 수 선정이 **G3 필수**(Q26). 해당 모델의 Modbus TCP 클라이언트 지원은 미확인이라 ③에서 확인(SRS §9 #14). "운전에 필요한 파라미터" 목록은 ③에서 FR-016 파라미터 기준으로 제안.
5. 유상 범위: 기본 화면 외 추가 화면, 이지뷰·M2I 외 메이커용 화면 데이터는 추가 비용(금액 미정, COST-005, G6·Q28). 설계는 기본 화면 범위만 대상으로 한다.
6. 레지스터 맵: 모델별 전체 맵을 한국어로 공개(NFR-022 필수). 축 1 주소는 두 모델 공통 [가정](§2.1). 이더넷/TCP 부하와 펄스 지터·누락을 함께 실측해야 함(SRS §9 #12).
7. 출력 전기 형식: 차동 필수, 24 V 오픈 컬렉터 연결 권장 [가정](NFR-005). (b) 불가 시 G3에 보고.
8. 안전·I/O·운전: 원점·리밋·비상정지·드라이브 알람/완료 입력 필수(FR-008~011, 모델별 축 수만큼). JOG 필수(FR-019, v0.7 상향). 비상정지는 보조 정지(NFR-020). 절연 필수, 내압·이더넷 포트 절연 수준은 ③에서 규격 근거로 제안(NFR-009).
9. 전원·환경·기구: 24 VDC ±10% [가정], 0~55 ℃ [가정], DIN 레일, 분리형 단자, 치수는 모델별 미확인(NFR-007·012·017). 원가 잠정 약 9만원(1축·2축 공통, 패널 제외, D-016·D-018, COST-001), 국내 경쟁가 수집 후 확정 조건 유지(D-011).
10. ③에서 할 확인: 두산 라인업과 대표 모델 3종 → §3.1(Q1-잔여), 이지뷰·M2I 대상 패널 모델(G3 필수)·Modbus TCP 지원·이더넷 사양(Q26), 두 모델 공용화 방식(CON-011), MCU(ESP32/STM32, CON-001, G3).
