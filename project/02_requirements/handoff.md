## 2. 다음 단계가 반드시 알아야 할 핵심 내용 (최대 10줄)
1. 라인업: 축 수(1축/2축, D-015) × HMI 통신(TCP/RTU, D-034) = 4개 조합(SRS §2.1, CON-011). [TCP 모델]은 유선 이더넷 Modbus TCP 서버(FR-022, HMI 이더넷 포트 1개 = 온보드 포트, D-041), [RTU 모델]은 RS-485 Modbus RTU 슬레이브(FR-025). 같은 축 수에서 레지스터 맵·기능 동일(FR-026).
2. **v1 필수 I/O(D-044, CON-015):** 입력 START(FR-028 신규, 동작 정의 Q38)·STOP(EMG)(= FR-010 비상정지), 출력 서보 ON(FR-011(c) 권장 → 필수, D-042). 나머지 DI·DO는 예비.
3. **우선순위 하향:** FR-008(원점 센서 원점복귀)·FR-009(센서 리밋)·FR-011(a)(b)(드라이브 알람·완료 입력)는 '미확정(I/O 사양 확정 시 재검토)'. 삭제하지 않았다. v1 설계·검증 대상에서 일단 빠진다. SCH-REC S-01(DI 11점 대 4점)은 v1 범위에서 해소 방향.
4. FR-021 진단 입력 상태는 사용 I/O(START·STOP(EMG)·서보 ON)로 줄였다. 원점·리밋·알람·완료는 보류.
5. **원점복귀(D-045, Q35 답변):** FR-023 (b)의 원점복귀 운전 조작은 미확정. 원점복귀 기능(원점 입력 포함)은 필요 시 추가하며 I/O 확정 때 재검토. 기본 화면·시험에서 원점복귀는 일단 뺀다. 나머지 (b)(시작·정지·JOG·알람 해제)와 (a)(c)(d)는 필수.
6. **펄스 출력 형식:** 차동만 제공(NFR-005(a) 필수, D-046). 24 V 오픈 컬렉터(NFR-005(b))는 v1 범위 밖. Pulse/Direction 확정(채널 A = 펄스, B = 방향, D-048, FR-001). CW/CCW(FR-002)는 v1 범위 밖.
7. [2축 모델] I/O 구성(서보 ON 축별/공용, START·STOP 공용 여부, 예비 DI·DO 배정)은 미확정(Q37). FR-011(c)는 [1축 모델] 1점만 확정.
8. D-041: EtherCAT 마스터와 그 예비 이더넷 포트는 이번 범위 밖(CON-002, CON-010). 온보드 이더넷은 [RTU 모델]에서 뺄 수 없을 수 있어 CON-013 문구 처리를 Q39(G3 필수)로 올렸다.
9. FR-016·FR-018 경로: [RTU 모델] 보드 USB(D-037, CON-014), [TCP 모델] 이더넷(DC-09 제안), [TCP 모델] USB 병행 미확인(Q34). 화면 데이터(FR-024)는 RTU 전용 패널 포함(D-038), Q30 조사 중.
10. 대표 드라이브 미쓰비시·LS·대우(D-026), 모델 미확인(Q1-잔여). 잠정 판매가는 참고(COST-006, TCP/RTU 차등 D-040, 금액 G6). 2축 실측 보류(D-030).
