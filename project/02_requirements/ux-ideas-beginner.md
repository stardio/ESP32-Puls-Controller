# 초보자용 사용성 아이디어 (제안, SRS 미반영)

작성: 메인 세션, 2026-11-01. 대상: 서보·PLC 경험이 적은 설비 담당자(D-005).
원칙: 하드웨어 원가를 늘리지 않는다(펌웨어·HMI 화면·문서로 해결). 기존 레지스터(di_raw 0x0031, boot_status 0x002D, reset_reason 0x002C)를 최대한 재사용한다.

## 초보자가 막히는 지점 → 해결 아이디어

| 막히는 지점 | 아이디어 | 구현 | 효과 |
|---|---|---|---|
| "펄스 수"와 "전자기어"가 어렵다 | **A. 실제 단위 운전**: 리드(mm)·1회전 펄스 수만 한 번 넣으면 이후 위치는 mm 또는 °, 속도는 mm/s 또는 rpm으로 입력. 내부에서 펄스로 변환 | 펌웨어(단위 변환 파라미터 3개) + HMI | 매우 큼 |
| 처음 설정 순서를 모른다 | **B. 첫 설정 마법사**(HMI, 첫 부팅 시 자동): ① 축 수 → ② 1회전 펄스 수 → ③ 리드 → ④ 최고 속도 자동 계산(1 MHz·드라이브 한도 안인지 판정) → ⑤ 시험 운전 | HMI 화면 5장 + 계산 레지스터 | 매우 큼 |
| 배선이 맞았는지 모른다 | **C. 배선 점검 화면**: STOP 입력(정상/끊김), START 입력, 펄스 출력 자기확인(PCNT 루프백 카운트 증가), 서보 ON 출력, 통신 상태를 초록·빨강으로 표시 | 기존 레지스터 재사용, HMI 1장 | 큼 |
| 처음 돌릴 때 무섭다 | **D. "모터 돌려보기" 버튼**: 저속(예: 60 rpm 상당)으로 정·역 1회전씩만 움직이는 시험 운전. 손을 떼면 감속 정지(홀드형) | 펌웨어 시험 운전 명령 1개 | 큼 |
| 알람 의미를 모른다 | **E. 한글 알람 + 조치 방법**: "STOP 입력이 끊겼습니다 → J15 2번 단자 배선 확인" 식으로 원인과 조치 표시 | HMI 문자열 테이블(알람 코드 §5.8 기반) | 큼 |
| 여러 위치를 반복 운전하고 싶다 | **F. 포인트 테이블**: 위치·속도 8개를 저장하고 HMI 버튼으로 호출. 현재 위치를 그대로 저장하는 "티칭" 버튼 | 펌웨어(NVS 테이블) + HMI | 중간~큼 |
| 설정을 잃어버리거나 다른 장비에 복사하고 싶다 | **G. 설정 백업·복원·초기화**: PC 도구(USB)로 파일 저장/불러오기, 공장 초기화, IP 분실 시 초기화(I-037 해결) | PC 도구 + 펌웨어 | 중간 |
| 매뉴얼을 찾기 귀찮다 | **H. 케이스 QR 코드**: 배선도·5분 셋업 영상·계산기·화면 데이터로 바로 연결 | 라벨 인쇄 | 중간 |
| 드라이브 쪽 배선이 헷갈린다 | **I. 드라이브별 배선 카드**(대우·LS·미쓰비시): 컨트롤러 단자 ↔ 드라이브 단자 대응표 1장. 이후 사전 결선 케이블 옵션 판매 검토 | 문서(실물 매뉴얼 확인 후) | 중간 |
| 보드 없이 미리 익히고 싶다 | **J. PC 시뮬레이터 모드**: PC 도구에서 가상 컨트롤러로 HMI·Modbus 동작 연습 | PC 도구(Python) | 작음~중간 |

## 우선순위 (권고)
1. **1순위 (v1, 출시 전):** A 실제 단위 운전, C 배선 점검 화면, E 한글 알람 + 조치, H QR 코드. 화면과 문자열 위주라 비용이 작고 문의 전화를 가장 많이 줄인다.
2. **2순위 (v1 가능하면):** B 첫 설정 마법사, D 모터 돌려보기, G 백업·복원·IP 초기화
3. **3순위 (v1.1):** F 포인트 테이블, I 드라이브별 배선 카드·사전 결선 케이블, J 시뮬레이터

## 마케팅 연결
"전자기어 몰라도 mm로 입력", "배선 점검 화면이 알려 줍니다", "알람에 조치 방법까지 한글로" — 데모 영상과 상세페이지의 핵심 문구로 쓸 수 있다(G6 이후).
