## 1. 개요

- **목적:** 펄스 열(Step/Dir) 입력형 서보·스테퍼 드라이브를 구동하는 다축 펄스 컨트롤러의 요구사항을 검증 가능한 형태로 정의한다. ③ 설계 단계의 입력이 된다.
- **범위:**
  - 제품 라인업(D-015): 1축 모델과 2축 모델 2종. 모델 간 차이는 축 수와 그에 따른 항목(§2.1)이며, 그 밖의 차이는 [가정]으로 없다고 본다(Q27).
  - 포함: 펄스 열 출력, 위치결정 운전, Modbus 상위 통신(HMI 패널과 Modbus TCP 연동 포함, D-017), 산업 현장 I/O(원점·리밋·비상정지·드라이브 상태), 시운전·진단 기능, PC 설정 도구, 설정 저장, 사용자 문서(연결 가이드·연동 예제), HMI 표준 화면 데이터(D-020. 패널 자체는 제외, D-018. 대상은 표준 지원 메이커 이지뷰·M2I 패널(D-021), 범위는 기본 화면(D-022)), 전장·기구(D-002).
  - 유상 별도(기본 공급 범위 밖, 금액 미정·G6): 기본 화면 외 추가 화면, 표준 지원 메이커 외 패널용 화면 데이터 제작(D-021, D-022, COST-005).
  - 제외(v1): 버스형 서보 네트워크(SSCNET 등) 직접 구동(CON-003), 수 Mpps급 고주파 영역(CON-004), G-code 해석 기반 CNC 기능 [가정], 다축 보간(FR-014), 무선 설정(FR-017), 엔코더 피드백 입력(D-012 확정), 기능안전·IATF 16949 인증 대응(CON-010) [가정].
- **목표 고객(D-005):** 자동차 부품 2·3차 협력사의 설비 개조·레트로핏 담당(설비/생산기술팀). 수요 규모는 미확인이다(MR §6, SUM 핵심 발견 1). 고객 페인포인트(자본 34%, ROI 31%, 인력 29%, 호환 28%)는 미국 설문을 국내에 적용한 [가정]이다(MR §4). 사용자 결정에 따라 재확인 없이 [가정]으로 계속 진행한다(D-013, Q19).
- **차별 요소 후보 [가정](MKT-18):** (1) 산업 환경 내성(절연·24 V·노이즈: NFR-007~009, NFR-013), (2) 설정·연동 용이성(FR-016, FR-021, NFR-015, NFR-018, NFR-019), (3) PLC 제조사에 묶이지 않는 개방형 Modbus 연동(FR-004, D-006), (4) 한국어 문서·기술 문의(NFR-016, NFR-021). 각 항목은 해당 요구사항의 검증 결과로 증명되기 전에는 마케팅 주장으로 쓰지 않는다. 가격 우위는 검증할 수 없는 가설이므로 차별 요소에서 뺀다(MKT-19, COST-002).
- **용어 정의:**

| 용어 | 정의 |
|---|---|
| 펄스 열(Step/Dir) | 펄스 1개당 지령 1단위를 이동하고, 방향 신호로 회전 방향을 지정하는 위치 지령 방식 |
| CW/CCW (정/역 펄스) | 정방향 펄스선과 역방향 펄스선을 따로 두는 펄스 지령 방식 |
| pps | pulses per second. 본 문서에서 kpps = 1,000 pps, 1 kpps는 펄스 주파수 1 kHz와 같다 |
| 축 | 독립된 펄스 출력 채널 1개와 그에 딸린 방향·I/O 신호 묶음 |
| 모델 | 축 수로 구분한 판매 단위. 1축 모델(축 1개)과 2축 모델(축 2개)이 있다(D-015) |
| 상위 장치 | 컨트롤러에 Modbus로 접속해 지령·조회를 하는 장치(PLC, PC, HMI 패널) |
| HMI 패널 | 5인치 또는 7인치 산업용 범용 터치패널(D-017). 표준 지원 메이커는 이지뷰·M2I(D-021)이며 기종·모델은 미확인(Q26, G3)이다. 패널은 본 제품의 원가·공급 범위 밖이며 고객이 별도로 준비한다(D-018) |
| 표준 지원 메이커 | 당사가 기본 화면 데이터를 제작·제공하는 HMI 패널 메이커. 이지뷰, M2I(D-021). 그 외 메이커용 화면 데이터 제작은 추가 비용(금액 미정)이다 |
| 기본 화면(기본 틀) | 당사가 기본 제공하는 HMI 화면 범위. 운전에 필요한 모든 데이터와 파라미터를 포함한다(D-022). FR-023 (a)~(d)에 해당한다. 기본 틀 외 추가 화면은 추가 비용(금액 미정)이다 |
| 레지스터 맵 | 컨트롤러가 Modbus로 노출하는 데이터의 주소·데이터형·단위·읽기/쓰기 속성·값 범위 목록 |
| 레트로핏 | 기존 설비의 제어부를 교체·개조하는 작업 |
| 대표 드라이브 | 요구 수치 산정과 연결 가이드 작성의 기준으로 삼을 서보 드라이브 3종. 제조사는 미쓰비시·LS·두산 각 1종(D-009). 모델은 미확인이며 ③단계에서 확인한다(Q1-잔여) |
| JOG | 시운전을 위해 사용자가 수동 지령으로 축을 일정 속도로 움직이는 운전 |
| 소프트웨어 리밋 | 설정한 위치 범위를 넘는 이동 지령을 막는 기능. 센서 입력(FR-009)과 별개다 |
| v1 범위 밖 | 요구사항 ID는 남기되 첫 출시 제품에서는 구현·검증하지 않는 항목 |
| 미확인 | 근거가 없어 값을 정하지 못한 항목. G2 전후에 확인 필요 |

### 3.1 필요 펄스 주파수 산정표 (NFR-001·002 입력, MKT-14)

필요 주파수(kpps) = 지령 분해능(펄스/회전, 전자기어 적용 후) × 최고 회전수(rpm) ÷ 60 ÷ 1,000

| # | 대표 드라이브(제조사·모델) | 지령 분해능(펄스/회전) | 최고 회전수(rpm) | 필요 주파수(kpps) | 200 kpps 대비 | 출처 |
|---|---|---|---|---|---|---|
| 1 | 미쓰비시(D-009) · 모델 미확인(Q1-잔여) | 미확인 | 미확인 | 미확인 | 미확인 | 데이터시트(미확인) |
| 2 | LS(D-009) · 모델 미확인(Q1-잔여) | 미확인 | 미확인 | 미확인 | 미확인 | 데이터시트(미확인) |
| 3 | 두산(D-009) · 서보 제품 라인업·모델 미확인(Q1-잔여) | 미확인 | 미확인 | 미확인 | 미확인 | 데이터시트(미확인) |

> [2축 모델]의 동시 운전 기준도 200 kpps(D-010, D-015)이므로, 이 표의 필요값은 NFR-001과 NFR-002 모두의 D-007 재검토 판단 근거가 된다. 두산은 ①단계 조사 대상이 아니어서 펄스 열 입력형 서보 제품이 있는지부터 ③에서 확인해야 한다(§9 이슈 #8).

> 계산 예시 [가정, 출처 없는 값]: 10,000 펄스/회전 × 3,000 rpm ÷ 60 = 500 kpps. 이 경우 200 kpps로는 1,200 rpm까지다. 전자기어비로 지령 분해능을 낮추면 필요 주파수는 줄지만 위치 분해능이 떨어진다(MKT-14). 실제 값은 대표 드라이브 데이터시트로 채운다.

## 5. 원가 목표 (COST)

> 모든 COST 항목은 "조건부"다(MKT-23, D-011). 사용자는 원가 목표를 조건부로 G2에 올리는 데 동의했다(D-011). 수량 시나리오와 판매가 목표 비율은 답이 없어 미확인이다(Q11-잔여). 확정 조건: 국내 경쟁 구성 KRW 가격(최소 3개 제품) 수집(이슈 #2) 후 사용자가 목표값을 정한다. 판매가는 G6에서 확정하며, 그 전에는 모든 가격을 "제안"으로 표기한다.
