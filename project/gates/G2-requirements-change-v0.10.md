## 조건
사용자가 "조건부 승인"으로 응답했다(2026-11-04). 조건을 따로 고르지 않았으므로, 승인 요청 때 제시한 조건 후보 C1~C6을 모두 조건으로 적는다. 사용자가 조건을 바꾸면 이 표를 고친다.

| # | 조건 | 기한 |
|---|---|---|
| C1 | I-049 패닉 리셋 원인 분석과 재현 시험(시리얼 로그 상시 수집) | ⑤ 시험 시작 전 |
| C2 | I-050 park 순간 펄스 잘림을 오실로스코프로 확인 | ⑤ 시험 시작 전 |
| C3 | 펌웨어 단위시험(fw_interp, stream, start_all, 0x0150 블록) 작성·실행(gcc 환경) | ⑤ 시험 시작 전 |
| C4 | code-reviewer 재리뷰와 Minor 9건 처리 방침 결정 | ⑤ 시험 시작 전 |
| C5 | NFR-025 경로 오차 한도를 ⑤ 실측 분포로 확정, 실측 기록 문서화 | ⑤ 단계 |
| C6 | FR-041 시연 합격 기준을 ⑤ 시험 설계에 반영 | ⑤ 단계 |
