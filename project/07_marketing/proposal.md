# 제안서 (초안) — 설비 레트로핏용 1축 펄스 위치결정 컨트롤러

| 문서 | 버전 | 작성 | 작성일 | 상태 |
|---|---|---|---|---|
| PRP-001 | 0.1 | marketing-strategist | 2026-10-30 | **초안(D-031 예외).** 협력사 설비/생산기술팀 대상. 외부 발송 금지. 가격 미기재. G6 재검토 |

> 표기: **검증** = 1축 구현 실측 기록, **설계 목표(미검증)** = SRS 값, **[가정]** = 근거 없는 가정(고객 인터뷰 없이 작성, D-008·D-013). 도입 효과는 전부 [가정]이며 수치를 쓰지 않는다. 인증(KC 등)은 취득·확인된 것이 없다.

## 1. 제안 배경 [가정]

노후 설비의 제어부를 교체하거나 서보 축을 추가할 때 설비/생산기술팀이 흔히 겪는 어려움(미국 설문을 국내에 적용한 [가정], MR §4):
- 초기 투자 부담과 효과 설명의 어려움
- 숙련 인력 부족: 위치결정 모듈 설정과 PLC 프로그램 개발 부담
- 기존 서보 드라이브·PLC와 호환되는지에 대한 불안

본 제안은 이 가운데 "기존 펄스 입력형 서보 1축을 PLC 위치결정 모듈 없이 단독으로 구동하고 싶은 경우"를 대상으로 한다.

## 2. 제안 제품 요약

| 항목 | 내용 | 구분 |
|---|---|---|
| 형태 | 펄스(Step/Dir) 출력 1축 위치결정 컨트롤러, 24 VDC, DIN 레일 설치 | 설계 목표(미검증) |
| 최대 펄스 | 1 MHz(1축 구현에서 외부 측정 1 µs 주기, 1,000,000 펄스 계수 일치, 실제 모터 운전은 사용자 보고) | 검증(측정 조건은 catalog.md V1) |
| 상위 연동 | Modbus TCP 서버(포트 502) 내장, PLC·PC·HMI에서 읽기/쓰기. 레지스터 맵 한국어 공개 예정 | 서버 동작 검증 / 문서 설계 목표 |
| 현장 기능 | 원점복귀, 리밋 정지, JOG, 진단(입력 상태·정지 원인·알람 이력) | 설계 목표(미검증) |
| HMI | 이지뷰·M2I 패널용 기본 화면 데이터 제공. 패널은 고객이 별도 준비 | 설계 목표(미검증) |
| 2축 모델 | 출시 예정(사양 미확정) | – |

## 3. 레트로핏 시나리오 [가정]

> 시나리오는 협력사 설비의 일반적 사례를 가정한 것이며 실제 사례가 아니다. 현장 평가에서 대상 설비에 맞춰 수정한다.

### 시나리오 A: PLC 위치결정 모듈 교체
- 현황 [가정]: 1축 서보를 PLC 위치결정 모듈(예: 200 kpps급)로 구동 중. 모듈 단종·고장 또는 PLC 교체 부담.
- 개선 방안: 컨트롤러를 서보 드라이브 펄스 입력에 연결하고, PLC는 Modbus TCP로 목표 위치·속도·시작 명령을 쓰고 상태를 읽는다.
- 확인 사항: PLC가 Modbus TCP 마스터(클라이언트)를 지원하는가. 대표 PLC 연동 예제는 설계 목표(NFR-019, 대상 PLC 미정).
- 기대 효과 [가정]: PLC 위치결정 모듈 의존 감소, 교체 공수 감소(정량 효과 미확인).

### 시나리오 B: 노후 전용 컨트롤러 교체 + HMI 신규
- 현황 [가정]: 구형 위치 제어기로 단독 운전 중. 조작 패널 노후.
- 개선 방안: 컨트롤러 + 범용 터치패널(이지뷰·M2I)에 기본 화면 데이터를 내려받아 운전·파라미터·진단 화면 구성.
- 확인 사항: 패널 기종 확정(G3), 기본 화면 내 파라미터 목록 확인.
- 기대 효과 [가정]: 화면 제작 부담 감소, 파라미터 조정과 알람 확인을 한 화면에서 처리.

### 시나리오 C: 라인 개조로 보조 축 추가 (PLC 없이)
- 현황 [가정]: 소형 보조 이송축 1개 추가가 필요하나 PLC 입출력·모듈 여유가 없음.
- 개선 방안: 독립형 컨트롤러로 JOG·원점복귀·위치 이동을 구성하고, 필요하면 상위 PLC와는 Modbus TCP로 시작/완료 신호만 교환한다.
- 단독 시퀀스 실행(FR-013)은 권장 요구이며 미검증이다.
- 기대 효과 [가정]: 설비 개조 범위 축소.

## 4. 도입 절차 제안 (일정 미정)

| 단계 | 내용 | 고객 부담 |
|---|---|---|
| 1. 사전 검토 | 대상 서보 드라이브 모델, 펄스 입력 형식(차동/오픈 컬렉터), 지령 분해능, 최고 회전수 확인. 필요 펄스 주파수 = 분해능(펄스/회전) × rpm ÷ 60 | 드라이브 사양서 제공 |
| 2. 현장 평가 | 연결 확인, 배선 확인, 시운전(JOG, 원점복귀) | 설비 정지 시간 협의 |
| 3. 파일럿 | 1축 시범 적용, 운전 기록 수집, 피드백 | 시험 대상 설비 지정 |
| 4. 확대 적용 | 조건 확정 후 구매(가격은 별도 견적) | – |

## 5. 사전 확인 체크리스트 (고객 기입용)

| # | 확인 항목 | 이유 |
|---|---|---|
| 1 | 서보 드라이브 제조사·모델 | 연결 가이드 대상 여부(미쓰비시·LS·대우 모델은 미확인) |
| 2 | 펄스 입력 방식(Step/Dir 또는 CW/CCW)과 전기 형식(차동/24 V 오픈 컬렉터) | NFR-005 |
| 3 | 지령 분해능, 필요 최고 회전수 → 필요 kpps | 1 MHz 이내인지, 2축 계획이면 200 kpps 동시 요건 |
| 4 | 상위 PLC 기종과 Modbus TCP 지원 여부 | 연동 예제 대상 |
| 5 | HMI 패널 메이커·모델 | 이지뷰·M2I 표준 지원 여부, 그 외 추가 비용 |
| 6 | 설치 환경(온도, 전원 24 VDC 여부) | NFR-007, NFR-012 |
| 7 | 안전 회로 구성(하드와이어 비상정지 등) | 컨트롤러 비상정지는 보조 정지 |

## 6. 도입 효과 (전부 [가정], 파일럿에서 측정)

| 효과 영역 | 가설 [가정] | 측정 방법 후보 |
|---|---|---|
| 초기 비용 | PLC 모듈+개발 공수 구성 대비 비용 부담 감소 가능 | 고객의 현재 구성 견적과 비교(총비용 자료 미확보) |
| 시운전 시간 | JOG·진단·한국어 가이드로 단축 가능 | 현장 평가 시 소요 시간 기록(NFR-015) |

수치(%, 시간, 원)는 근거가 없어 쓰지 않는다.

## 7. 한계와 고지

1. **비상정지 입력은 보조 정지이며 안전 회로를 대체하지 않는다.** 기능안전 인증 없음. (NFR-020)
2. 인증: KC 등 인증 대상 여부와 취득 현황은 확인 전이다. 이 문서는 인증을 주장하지 않는다.
3. 성능 수치의 "검증"은 개발 단계 측정이며 보증 사양이 아니다. 1 MHz 측정은 MCU 핀 기준이고 절연·차동 출력단과 드라이브 입력단 파형은 검증 전이다.
4. 대상은 펄스 열 입력형 서보다. 버스형 서보는 직접 구동하지 못한다. 수 Mpps 영역은 대상이 아니다.
5. 무선 설정은 없다(v1). 엔코더 피드백 입력은 없다(v1 제외, D-012). 위치는 출력 펄스 수 기준이다.
6. 2축 모델은 출시 예정이며 사양·가격은 확정되지 않았다.
7. 가격: **확정 전.** 본 초안에는 가격을 싣지 않으며, 가격은 G6 이후 견적서로 제시한다. 패널은 별도, 기본 화면 외 추가 화면과 표준 지원 외 패널용 화면 데이터는 추가 비용이 발생한다(금액 미정).
8. 공급 기간·단종 통보·기술 문의 채널: 정책 미확정(NFR-021).

## 이슈 제기
- 시나리오 A~C는 [가정]이며 실제 협력사 사례로 검증하지 못했다(D-008). 첫 협력사 인터뷰 후 시나리오를 교체해야 한다.
- 대표 PLC 연동 예제 대상(Q18)이 미정이라 시나리오 A의 PLC 연동 문구는 일반 표현이다.
- 파일럿 참여 조건·보증 정책이 없어 제안서 발송 가능 상태가 아니다.
