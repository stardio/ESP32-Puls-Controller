# 데모 영상 대본: "5분 셋업" (본편 4~5분, 가로 16:9)

작성: 메인 세션, 2026-11-01. 온라인 마케팅 아이디어 #1.
근거: 설계 기준선 v0.4.2(핀·커넥터), D-020~D-022(HMI 화면 제공), D-028(1축 1 MHz 실모터 운전), D-041(IP101 192.168.0.220), D-058·D-072(STOP 동작).
제약: 가격 언급 금지(G6 전). 성능은 1축 검증값만 쓴다. 2축은 "출시 예정"으로만 언급한다. 인증 관련 표현은 쓰지 않는다.
대상 시청자: 자동차 부품 협력사 설비/생산기술팀 엔지니어(D-005).

## 업로드 정보
- **제목 후보**
  1. PLC 없이 서보 1축 셋업 5분 | 펄스 컨트롤러 + 터치패널
  2. 박스 개봉부터 서보 회전까지 5분, 배선 그대로 보여드립니다
- **설명:** 서보 드라이브를 펄스열(차동)로 운전하는 컨트롤러의 셋업 전 과정입니다. 24 V 전원, 펄스 배선, 터치패널(Modbus TCP) 연결, 운전, STOP 동작까지 한 번에 보여 드립니다. 이지뷰·M2I용 HMI 화면 데이터를 함께 제공합니다. 필요 펄스 주파수 계산기: (링크) / 레지스터 맵: (링크)
- **챕터:** 00:00 소개 / 00:20 구성품 / 00:50 전원 / 01:20 펄스 배선 / 02:00 패널 연결 / 02:40 첫 운전 / 03:30 STOP / 04:10 정리
- **썸네일:** 왼쪽 터치패널, 오른쪽 서보모터, 큰 글자 "PLC 없이 5분"

## 촬영 준비 체크리스트
- **장비:** 시제품 1축 캐리어 + P4 보드, 24 V 전원, 서보 드라이브·모터 1세트, 7인치 패널(이지뷰 또는 M2I), 오실로스코프, 외부 START·STOP 스위치(STOP은 NC 접점)
- **펌웨어·화면:** 제품 펌웨어 1축 TCP 빌드, 제공용 HMI 화면 데이터(목표 펄스와 출력 펄스를 나란히 표시)
- **드라이브:** 전자기어를 1 MHz 운전이 최고 회전수 이내가 되도록 설정. 계산기로 확인
- **안전:** 모터 축 무부하, 고정 지그 사용. 촬영 중 비상정지 스위치를 손 닿는 곳에 둔다
- **카메라:** 부감 1대(책상 전체), 클로즈업 1대(단자·패널). 단자 번호가 읽히게 조명
- **자막·인서트:** 단자 번호와 신호명은 회로도 r2 기준(J5, J7, J15, J6)으로 표기

## 촬영 전 확인 필요 (실물)
- 드라이브 펄스 입력 단자 번호와 차동 입력 허용 주파수(사용 드라이브 매뉴얼)
- 제품 펌웨어의 PC 빌드·플래시 성공 여부(현재 호스트 시험만 통과, ESP-IDF 빌드 미확인)
- 상태 LED가 보드에 있는지(없으면 전원 장면에서 패널 부팅 화면으로 대체)

가격, "최저가", "업계 최초·최고", "2축 동시 1 MHz", 인증(KC 등), "안전 기능"(STOP 차단은 인증 안전 기능이 아님. 비상정지는 별도 안전 회로로 구성해야 한다는 안내를 설명란에 둔다)
