### 1.1 해석과 한계
1. **단순 비교 범위:** 1축 독립형(Autonics) 183,040~298,870원, PLC 위치결정 모듈(LS) 322,520원, 리셀러 참고가 978,391원(Mitsubishi). 판매처 간 편차가 크다(같은 Autonics 제품이 약 1.6배 차이).
2. **PLC 모듈은 단품 비교가 안 된다.** LS·Mitsubishi 모듈은 PLC 본체·전원·베이스·프로그램 개발 공수가 추가로 든다. COST-002가 요구한 "축당 총비용" 비교는 PLC 구성 가격과 공수를 조사하지 못해 **불성립**이다(I-018 부분 해소).
3. **VAT 기준이 제각각**이다(제품 1만 VAT 포함 확인). 가격 비교 시 VAT 포함 기준으로 환산해 근사한다.
4. **가격 우위 주장은 하지 않는다.** 기능 범위가 달라(Autonics 4 Mpps 간접, 우리는 Modbus TCP·HMI 화면 포함) 동급 비교가 아니다(MKT-19).
5. 공식 정가·대리점 견적은 확보하지 못했다. 대리점 견적 요청이 필요하다.

## 2. 원가 기준

| 항목 | 값 | 근거·주의 |
|---|---|---|
| 제조원가 잠정 | 약 90,000원 | D-016, D-018. 1축·2축 공통 기준, 패널 제외. COST-001 정의는 "BOM+조립" |
| 포함되지 않은 것 | 인증·시험 비용(COST-003), 보증·A/S, 유통 마진, 개발비 회수, 영업비 | 모두 금액 미확인 |
| 위험 | 2축 BOM 확인값 약 91,400원([가정] 환율)으로 9만원 초과 가능(I-029). 가격은 검색 스니펫 기반(I-031) | 1축 원가는 별도 확정값 없음. 9만원을 1축에 그대로 적용했다 |
| 수량 시나리오 | 미확인(COST-004, Q11-잔여) | 개발비·인증비 대당 배분 불가 → 손익분기 계산 불가 |

**산식:** 판매가(공급가, VAT 별도) = 원가 ÷ (1 − 총이익률). 총이익률은 인증·A/S·영업비를 빼기 전 값이다.

## 3. 판매가 제안 (1축 모델, 공급가 기준, VAT 별도)

| 안 | 제안가(공급가) | VAT 포함 환산 [산술] | 총이익률 [산술] | Autonics PMC-1HS-USB 모터마트(183,040, VAT포함) 대비 | 성격 |
|---|---|---|---|---|---|
| A 진입안 | **149,000원** | 163,900원 | 39.6% | 약 −10% | 파일럿·초기 도입 장벽 낮추기 |
| B 균형안 | **179,000원** | 196,900원 | 49.7% | 약 +8% | 기본 추천 [제안] |
| C 가치안 | **219,000원** | 240,900원 | 58.9% | 약 +32% (11번가 298,870 대비 약 −19%, LS 322,520 대비 약 −25%) | 인증·A/S·한국어 지원 비용 선반영 |

계산식 확인: 90,000÷(1−0.40)=150,000, ÷(1−0.50)=180,000, ÷(1−0.59)≈219,500. 제안가는 끝자리 정리를 위해 149,000 / 179,000 / 219,000으로 반올림했다. 환산 비율은 VAT 포함 제안가 ÷ 경쟁가로 계산했고, 경쟁가의 VAT 기준이 달라 ±10% 오차가 있다.

### 3.1 각 안의 근거와 위험

**A 진입안 (149,000원)**
- 근거: 국내 최저 확인가(Autonics 183,040) 아래에서 시작하면 신규 브랜드의 구매 장벽 중 "자본 부담"(MR §4, [가정])을 낮춘다.
- 위험: 총이익률 약 40%에서 인증비·A/S·영업비를 제하면 이익이 거의 없을 수 있다. 유통 마진 25% [가정] 적용 시 실수취 111,750원(원가 대비 +24%)에 그친다. 가격이 낮으면 품질 신호가 약해질 수 있다.

**B 균형안 (179,000원)** — 기본 제안
- 근거: Autonics 1축 독립형 확인가 범위(183,040~298,870원)의 하단 근처다. 경쟁 대비 기능 범위(이더넷 Modbus TCP, HMI 기본 화면 데이터 포함)로 비슷한 수준을 설명할 수 있다. 총이익률 약 50%로 인증·A/S 비용 여유가 있다.
- 위험: VAT 포함 시 모터마트 가격보다 높아 "더 비싼데 이유는?" 질문이 나온다. 설명할 증거(M1~M3)가 준비되어야 한다. 유통 마진 25% [가정] 적용 시 실수취 134,250원.

**C 가치안 (219,000원)**
- 근거: 시장 확인가 범위(18만~32만원) 중간 이상. 한국어 문서·기술 지원·HMI 화면 포함이라는 서비스 가치를 가격에 반영한다. 유통 마진 25% [가정] 적용 시 실수취 164,250원으로 비용 여유가 가장 크다.
- 위험: 신규 업체가 인지도·A/S 실적 없이 받기 어려운 가격. 파일럿 결과가 좋을 때만 현실적이다.

### 3.2 제안 선택 기준 (G6 의사결정용)
- 수량 시나리오(COST-004)와 인증·A/S 비용(COST-003)이 확정되면 A/B/C 중 총이익 기준으로 재선택한다. 두 값이 없으면 안 간 비교는 임시다.
- 직접 영업(협력사 직접 판매)이 주 채널이면 B, 유통 입점 비중이 높으면 C 또는 B에 유통가 분리 설계 [가정].
- 파일럿 한정 조건으로 A를 쓰는 안(기간·수량 제한)도 가능하나 이 역시 G6 결정 사항이다.
- **2축 모델 가격 제안은 보류한다.** 근거: 원가 9만원 공통 가정(D-018)이지만 2축 BOM이 초과 위험(I-029)이고 2축 동시 운전은 미실측(I-025, D-030). 가격은 "출시 예정" 단계에서 쓰지 않는다.

## 5. 패널 별도·타 메이커·추가 화면 정책안 (D-018, D-021, D-022)

> **금액은 쓰지 않는다.** SRS COST-005와 D-021·D-022에 따라 금액은 미정이며 G6에서 사용자가 정한다. 아래는 정책 구조안이다.

| 항목 | 정책안(제안) | 근거 |
|---|---|---|
| 패널 | 컨트롤러 판매가에 포함하지 않는다. 고객이 직접 준비한다. 추천 패널 메이커는 이지뷰, M2I(기종·모델은 G3 확정) | D-018, D-021 |
| 기본 화면 | 컨트롤러 판매가에 포함. 운전에 필요한 모든 데이터와 파라미터를 다룬 기본 틀(상태 표시, 시작/정지·원점복귀·JOG·알람 해제, 파라미터 변경, 진단)을 표준 지원 메이커 패널용으로 제공 | D-020, D-022, FR-023·024 |
| 기본 화면 갱신 | 레지스터 맵 변경 시 기본 화면 데이터도 같은 시점에 갱신해 제공(변경 이력 공개 조건과 연동) | NFR-022 |
| 추가 화면 | 기본 틀 밖 화면은 **유상**. 산정 방식 후보: (a) 화면 수 기준 단가, (b) 공수(시간) 기준 견적, (c) 패키지(화면 N개 묶음). 후보 (b)를 기본 제안 [가정] | D-022, COST-005 |
| 타 메이커 패널 | 표준 지원 메이커 외 패널용 화면 데이터 제작은 **유상**. 최초 1회 이식비 + 이후 같은 메이커·기종 재사용 시 이식비 없음 [가정]. 조건: 해당 패널이 Modbus TCP 클라이언트를 지원하고 레지스터 맵으로 접근 가능할 것 | D-021, CON-012 |
| 지원 범위 | 화면 데이터 제공까지. 패널 설치·교육·현장 출장은 별도 협의 [가정] | – |
| 표준 지원 확대 | 타 메이커 요청이 반복되면 표준 지원 메이커로 승격 검토 [가정]. 기준(요청 건수 등)은 G6 | – |
| 산정 입력값 | 화면 제작 공수(시간), 시간당 단가, 기종당 검증 비용 모두 미확인 | G6 전 측정 필요 |

**제안 요약:** 기본 화면은 본체 가격에 포함해 "화면 때문에 추가 비용이 든다"는 인상을 막고, 추가·타 메이커 비용은 견적 방식으로 투명하게 설명한다. 단 본체 가격이 낮을수록(A안) 화면 제작 공수가 이익을 잠식하므로 A안 선택 시 기본 화면 범위를 엄수한다.

## 6. G6 확정을 위해 필요한 입력
1. 대리점 견적 또는 판매 페이지 직접 대조(I-005·I-012 도메인 허용 후).
2. PLC 구성 총비용(PLC 본체+모듈+개발 공수+배선) 견적 — COST-002 비교 기준.
3. 수량 시나리오(COST-004), 인증·시험 비용(COST-003), A/S·보증 정책(NFR-021).
4. 유통 구조 결정, 1축 원가 확정값(I-029).
5. 화면 제작 공수와 단가(§5).

## 이슈 제기
- I-006·I-018은 "제품 3종·가격 5건 확인"으로 **부분 해소**다. 2차 확인 값이고 PLC 총비용 비교가 빠져 COST-002는 여전히 불성립이다. status.md 갱신은 메인 세션이 판단한다.
- 같은 Autonics 제품의 국내 가격이 판매처에 따라 183,040~298,870원으로 크게 다르다. 기준 가격 선택에 따라 포지셔닝이 달라진다.
