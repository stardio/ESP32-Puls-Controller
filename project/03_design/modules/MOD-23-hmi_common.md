# 설계→코딩 인터페이스: hmi_common (HMI 기본 화면 공통 정의, 메이커 무관)

| 모듈 ID | 버전 | 작성 | 대상 언어/플랫폼 | 추적 SRS ID |
|---|---|---|---|---|
| MOD-23 | 0.1 | architect | HMI 화면 정의 문서 + 태그 CSV(MOD-20 생성), 메이커 무관 | FR-023, FR-024, FR-019, FR-021, NFR-020, CON-012, D-020~D-022 |

## 1. 책임 (이 모듈이 하는 일 / 하지 않는 일)
- 한다: D-022 "기본 틀" 화면 구성을 메이커·모델과 무관하게 정의한다. 화면 목록, 화면별 객체(표시·입력·버튼·램프), 각 객체의 태그(레지스터 주소·형·워드 순서·쓰기 방식), 표시 형식(단위·소수점·한국어 라벨), 1축/2축 변형, 5인치/7인치 배치 원칙, 경고·고지 문구. 이 정의가 MOD-24(이지뷰)·MOD-25(M2I) 작화의 유일한 입력이다.
- 하지 않는다: 메이커 작화 도구 프로젝트 파일 제작(MOD-24·25), 패널 공급(D-018 범위 밖), 기본 틀 외 추가 화면(COST-005 유상).

## 2. 의존성
- 사용: MOD-20 `hmi_tags.csv`, interface-spec §5.
- 사용하는 쪽: MOD-24, MOD-25, ⑥ 매뉴얼(화면 설명).

## 4. 제약 조건
- 패널 기능 의존 최소화: 모든 조작은 홀딩 레지스터 단어 쓰기(FC06/16)로 가능해야 한다(코일은 JOG 편의용, 패널이 코일 미지원이면 명령 레지스터 + 유지 요청 방식). 비트 단위 쓰기(읽기-수정-쓰기)는 쓰지 않는다(경합 방지).
- 32비트 값: 상위 워드 먼저(DC-15) — 메이커별 설정 항목으로 MOD-24·25에 명시.
- JOG 버튼: 누름 = JOG_POS/NEG(또는 코일 ON), 뗌 = JOG_STOP(또는 코일 OFF). 패널이 누르는 동안 주기 쓰기를 지원하지 않으면 컨트롤러 `jog_keepalive_ms` 감시가 HMI 주기 읽기로 충족되는지 확인(연결 단위 요청 감시이므로 화면의 주기 읽기로 유지됨 [가정]).
- 1축/2축: `axis_count` 읽기로 축2 객체 숨김 지원 여부는 메이커 기능 미확인 → 미지원 시 1축용·2축용 프로젝트 2종.
- 해상도: 5/7인치 모델 해상도 미확인(Q26) → 배치는 "7인치 기준 설계 후 5인치 축소" 원칙 [가정].
- 한국어 문구는 regmap.yaml `label_ko`와 알람 문구 표를 단일 원본으로.
