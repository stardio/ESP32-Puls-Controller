# 설계→코딩 인터페이스: hmi_m2i (M2I 패널용 기본 화면 데이터)

| 모듈 ID | 버전 | 작성 | 대상 언어/플랫폼 | 추적 SRS ID |
|---|---|---|---|---|
| MOD-25 | 0.1 | architect | M2I 작화 도구 프로젝트(도구명·버전 미확인) + Python 태그 변환 스크립트 | FR-024, FR-023, CON-012, D-021, D-022 |

## 1. 책임 (이 모듈이 하는 일 / 하지 않는 일)
- 한다: MOD-23 공통 정의를 M2I 대상 패널 기종(Q26에서 선정)별 화면 데이터로 만든다. 범위·절차는 MOD-24와 같다: 통신 설정(Modbus TCP 클라이언트, 워드 순서, 주소 규칙), 공통 CSV → M2I 가져오기 형식 변환, 화면 S00~S06·P01·P02, 1축/2축 변형, 배포 패키지.
- 하지 않는다: 공통 정의 변경, 기본 틀 외 화면(COST-005).

## 2. 의존성
- 사용: MOD-23, MOD-20 hmi_tags.csv, M2I 작화 도구(미확인), 시험용 실 패널.
- 사용하는 쪽: 고객, ⑥ 매뉴얼.
