# 설계→코딩 인터페이스: hmi_easyview (이지뷰 패널용 기본 화면 데이터)

| 모듈 ID | 버전 | 작성 | 대상 언어/플랫폼 | 추적 SRS ID |
|---|---|---|---|---|
| MOD-24 | 0.1 | architect | 이지뷰 작화 도구 프로젝트(도구명·버전 미확인) + Python 태그 변환 스크립트 | FR-024, FR-023, CON-012, D-021, D-022 |

## 1. 책임 (이 모듈이 하는 일 / 하지 않는 일)
- 한다: MOD-23 공통 정의를 이지뷰 대상 패널 기종(Q26에서 선정, 기종 수 미확인)별 화면 데이터로 만든다. 통신 설정(Modbus TCP 클라이언트, 서버 IP·포트·유닛 ID, 워드 순서 = 상위 워드 먼저, 주소 오프셋 규칙), 태그 가져오기(공통 CSV → 이지뷰 가져오기 형식 변환 스크립트, 형식 미확인), 화면 S00~S06·P01·P02 작화, 1축/2축 변형, 배포 패키지(프로젝트 파일 + 설치 안내).
- 하지 않는다: 공통 정의 변경(MOD-23에서만), 기본 틀 외 화면(COST-005).

## 2. 의존성
- 사용: MOD-23 screen_spec, MOD-20 hmi_tags.csv, 이지뷰 작화 도구(미확인), 실 패널(시연용, 공급 범위 밖이므로 시험용 구매 필요 [가정]).
- 사용하는 쪽: 고객(배포), ⑥ 매뉴얼.

## 4. 제약 조건
- 통신 설정의 주소 표기(0 기준/1 기준, 4xxxx) 규칙은 메이커 매뉴얼 확인 후 `addr_offset`으로 반영(미확인).
- 패널의 동시 접속·요청 주기는 컨트롤러 `max_clients`·NFR-010 측정값과 맞춘다.
- 화면 문구 한국어.
