## 2. 핀맵 (v0.2 기준선: ESP32-P4, Waveshare ESP32-P4-ETH)

> 기존 1축에서 쓰는 GPIO는 servo1axis 코드·hardware.json으로 확인한 값이다[E1][E2][E4][E7]. 축2 핀과 신규 입력 핀은 **보드 회로도·헤더 표 미대조로 전부 미확인**이다(PS-27). ESP32-P4 GPIO는 GPIO 매트릭스로 주변장치 신호를 라우팅한다(PCNT 핀은 임의 GPIO 선택 가능, ESP32-P4 데이터시트 PCNT 절). 스트래핑 핀·전압 도메인은 미확인.

### 2.1 펄스 생성 자원 배정 (ESP32-P4, 축당 MCPWM 그룹 1개 + PCNT 유닛 1개)

### 2.4 시험 펌웨어(TFW) 핀 사용

- TFW는 축1 = 기존 GPIO25/32/33, ESTOP = GPIO19를 쓴다. 축2 핀은 TFW 빌드 설정값(`TFW_AX2_PLS_GPIO` 등)으로 두고 PS-27 결과 전에는 사용자가 배선에 맞춰 지정한다(modules/TFW-02).

### 2.5 (대안) STM32F407VGT6 배정 — v0.1 유지

> 아래 §2.5.1~2.5.3은 v0.1의 STM32F407 배정이다. architecture §4.5 전환 조건이 성립할 때만 사용한다. **핀 번호와 AF 번호는 데이터시트·RM0090 미대조로 전부 미확인.**

#### 2.5.1 펄스 생성 자원 배정 (축당 타이머 2개)

| 신호 | 필요 MCU 자원(C1) | 후보 핀 | ESP32(C2) 대응 자원 | 비고 |
|---|---|---|---|---|

| AX1_DIR (DIR 또는 CCW) | TIM1 CH2 출력(Step/Dir 모드: 강제 출력 레벨, CW/CCW 모드: PWM) | 미확인 | RMT 채널 1 또는 GPIO | §4.3 참조. 같은 타이머의 두 채널로 두 모드를 모두 처리 |

### 4.2 Step/Dir 모드 (`pulse_mode` = 0, 필수, FR-001)

```
DIR   ‾‾‾‾‾‾‾‾‾‾‾‾\_________________________________   (방향 반전: dir_invert 파라미터)
                  |<- t_dir_setup ->|
PULSE ____________________________|‾|_|‾|_|‾|_ ...      (첫 펄스는 방향 확정 후 t_dir_setup 경과 뒤)
```

- 방향 = 정(+): DIR 비활성 레벨, 역(−): DIR 활성 레벨 [가정, dir_invert로 반전].
- `t_dir_setup`(방향 확정 → 첫 펄스): 파라미터 `dir_setup_us`. 기본값 [가정] 10 µs, 범위 1~1,000 µs [가정]. 대표 드라이브 요구값 미확인(PS-15).
- 방향 전환은 정지 상태에서만 일어난다(운동 계획이 0 속도를 거친 뒤 전환).

### 4.3 CW/CCW 모드 (`pulse_mode` = 1, 권장, FR-002)

- 정(+) 이동: PLS 단자(CW)로 펄스, DIR 단자(CCW)는 비활성. 역(−) 이동: DIR 단자(CCW)로 펄스, PLS 단자 비활성.
- ESP32-P4 구현(v0.2): 축 MCPWM 오퍼레이터의 제너레이터 A·B를 CW·CCW로 쓰고 방향에 따라 한쪽만 출력하거나, 제너레이터 1개를 정지 중 GPIO 매트릭스로 PLS/DIR 핀에 전환한다. PCNT는 두 핀을 각 채널로 계수(유닛당 채널 2개 필요, 미확인)하거나 활성 핀만 계수한다. 자원 확인은 TFW-02. Step/Dir 모드는 기존 1축과 같이 DIR = GPIO 출력.
- (대안) C1 구현: 축 PWM 타이머의 CH1·CH2를 각각 CW·CCW로 쓰고, 이동 방향에 따라 한 채널만 출력 활성화한다. 출력단 하드웨어는 두 모드에서 같다(architecture §2.4).
- 모드 변경은 해당 축 정지·서보 OFF 상태에서만 허용 [가정].

## 6. 비상정지 경로

```
 ESTOP 단자(24 V, NC 접점 [가정])
      │
      ├─► 포토커플러 A(TLP293-4 1채널) ─► 풀업/풀다운 ─► AM26C31 enable 입력(한 핀)  ──► 전 축 차동 출력 고임피던스
      │        (MCU 비경유, 하드웨어 1차 경로)              (다른 enable 핀은 비활성 레벨 고정)
      │                                                     └─► (조건부) OC 출력단 입력 AND 게이트 / 베이스 차단
      │                                                     └─► ESTOP_GATE_FB → MCU GPIO(되읽기 진단)
      │
      └─► 포토커플러 B(1채널) ─► MCU ESTOP_IN = GPIO19(D-027)
                                   ├─► (v0.2) MCPWM 그룹 0·1 GPIO 고장 입력 → 제너레이터 브레이크(하드웨어, 자원 미확인)
                                   └─► GPIO 엣지 인터럽트(최우선) ─► MOD-10: 전 축 force level·타이머 정지·래치
                                                                        → 위치 무효(estop_pos_policy=0)
                                                                        → 기동 명령 거부(cmd_result 0x10)
                                                                        → 해제: 입력 정상 + ESTOP_RELEASE
```

| 항목 | 규약 | 근거·상태 |
|---|---|---|
| GPIO19 극성(v0.2) | 기존 1축은 STOP = Active-LOW·내부 풀업(접점 닫힘 = 정지)·100 ms 디바운스[E5][E6]. 제품은 아래 페일세이프 규약에 맞춰 "포토커플러 OFF(전류 없음) → GPIO19 레벨 = 정지"가 되도록 회로·논리를 정하고 디바운스를 두지 않는다. 최종 극성은 DC-17 | D-027, DC-17 |
| MCPWM 고장 입력(v0.2) | GPIO19를 그룹 0·1 고장 입력에 연결해 오퍼레이터 브레이크(출력 Low 고정)를 건다. 고장 입력 수·한 GPIO의 다중 라우팅 가능 여부 미확인 → TFW-04. 핀 앞에서 멈추므로 PCNT 계수 = 핀 출력 | architecture §2.6 |
| 페일세이프 | 입력 전류 없음(단선·24 V 상실·접점 개방) = 비상정지. 포토커플러 OFF 시 enable 선이 "출력 비활성" 레벨로 가도록 풀업/풀다운 방향을 정한다 | [가정] NC 접점(이슈 #3) |
| AM26C31 enable 논리 | 공통 enable G, /G 두 핀[P8]. 두 핀 조합에 따른 출력 상태(기능표)는 **데이터시트 대조 필요(미확인)**. 설계 의도: 한 핀을 비활성 레벨로 고정하고 다른 핀만 비상정지 신호로 구동해, MCU가 enable을 켤 수 없게 한다 | PS-05, PS-10 |
| 응답 시간 | 1차 경로 = 포토커플러 응답 + AM26C31 enable/disable 전파 지연 약 10~19 ns[P8]. 포토커플러 응답 시간 미확인 → NFR-011 값은 T-05 실측 후 제안 | NFR-011 |
| 위치 일관성 | 차동 출력은 enable 뒤에서 펄스를 되먹임할 수단이 없다(수신기 추가 시 원가 증가). 따라서 기본은 **비상정지 후 위치 무효 + 원점복귀 요구**(`estop_pos_policy`=0). 게이트 앞에 논리 AND 게이트를 두고 그 출력을 계수하는 안(위치 유지)은 부품·가격 미확인(BOM C11) → DC-08 | architecture §2.4 원칙 4 개정 |
| 해제 | 입력 정상 복귀만으로는 해제하지 않는다. `sys_command`=1(ESTOP_RELEASE) 또는 PC 도구 해제 명령 필요. 해제 후에도 서보 ON·기동은 별도 명령 | FR-010 |
| 하드웨어 게이트 해제 시점 | 하드웨어 게이트는 입력 정상 복귀와 함께 열린다. 그러나 MCU 펄스 타이머는 래치로 정지 상태이므로 펄스는 나가지 않는다 | FR-010 |
| 리밋·드라이브 알람 | 해당 축만 MCU 경로(EXTI → MOD-07 즉시 정지)로 처리. 하드웨어 게이트에 묶지 않는다 | architecture §2.6 |
| 고지 | 이 경로는 보조 정지이며 안전 회로를 대체하지 않는다. HMI 비상정지 팝업·PC 도구·매뉴얼에 문구 표시 | NFR-020 |

**네트워크 워드(0x4000~0x400E) 잠금:** `unlock_key`(0x0102)에 0x4D56을 쓴 뒤 10 s 안에만 값 변경 가능(그 외 예외 03, 같은 값 재쓰기 허용). 쓰기만으로는 저장되지 않으며 `net_apply`(0x400F)=1 또는 SAVE로 저장, 적용은 REBOOT 후.

**D-072 반영:** 별도 해제 명령(ESTOP_RELEASE)은 없다. STOP 입력이 해제된 상태에서 들어온 시작 명령(물리 START 엣지 또는 Modbus 운전 시작)이 래치를 풀고 시작한다. §5.5·§5.8의 해제 명령 기술은 이 절로 대체한다.
