# 케이스 QR 라벨 사양 (FR-036)

| 항목 | 내용 |
|---|---|
| 위치 | 케이스 전면 또는 측면, 단자 라벨 옆 |
| 크기 | QR 15×15 mm 이상(인쇄 해상도 300 dpi 이상), 주변 여백 2 mm |
| 연결 대상 | 제품 지원 페이지 1개(아래 4개 링크를 모은 페이지). 링크가 바뀌어도 라벨을 다시 인쇄하지 않도록 고정 주소 사용 |
| 지원 페이지 내용 | ① 배선도(모델별) ② 5분 셋업 영상 ③ 펄스 주파수 계산기 ④ HMI 화면 데이터 다운로드(이지뷰·M2I) ⑤ 레지스터 맵 ⑥ 배선 카드(드라이브별) |
| 라벨 문구 | "설치 방법·배선도·화면 데이터" + 모델명 + 기본 IP 192.168.0.220 |
| 미정 | 지원 페이지 주소(도메인) — 사업 결정(G6) |
