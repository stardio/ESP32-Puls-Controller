# HMI 화면 구성안 (이지뷰·M2I 공통, FR-023·FR-024·FR-029~FR-034)

주소는 interface-spec §5와 §5.12 기준. 5인치(800×480 [가정])와 7인치(1024×600 [가정]) 두 해상도로 만든다.

## 화면 목록
| # | 화면 | 내용 | 주요 레지스터 |
|---|---|---|---|
| 0 | 시작 | setup_done=0이면 1번(마법사)으로, 1이면 2번(운전)으로 자동 이동 | 0x0130 |
| 1-1~1-5 | **첫 설정 마법사** | ① 축 수 확인(모델 표시) ② 1회전 펄스 수(자주 쓰는 값 버튼 + 계산기 QR) ③ 단위 선택(mm/°/펄스)과 리드·감속비 ④ 최고 속도: max_rpm_calc 표시, 목표 rpm이 넘으면 빨간 경고 ⑤ 모터 돌려보기 → 완료 시 setup_done=1 | +0x140~0x147, +0x032, 0x0130 |
| 2 | 운전 | 축별 현재 위치(단위), 목표 위치·속도 입력(단위), START/정지, 상태 표시(대기·운전·정지·알람) | +0x030, +0x04A~0x04C, axis_command 13/14/3 |
| 3 | **모터 돌려보기** | 큰 버튼 "+ 방향", "− 방향"(누르는 동안만 회전, 떼면 정지), 속도(rpm) 표시 | axis_command 15/16, test_rpm |
| 4 | **포인트** | 8개 포인트 목록(위치·속도), "이동" 버튼, "현재 위치 저장(티칭)" 버튼 | 0x6000~, axis_command 17/18, +0x04E |
| 5 | **배선 점검** | 항목별 초록/빨강: X STOP, X START, X 펄스 출력, X 서보 ON, (Y 동일), 이더넷, RS-485. 빨강 항목 옆에 "확인할 단자" 문구 | 0x0033 |
| 6 | **알람** | 현재 알람의 한글 문구·원인·조치(alarm-messages.md), 알람 해제 버튼, 이력 | 0x0034, 0x3000~ |
| 7 | 파라미터 | 운전 파라미터 전체(D-022), 단위 설정 | B+0x100~ |
| 8 | 시스템 | 펌웨어 버전, 통신 모드, IP, 리셋 원인, 공장 초기화·네트워크 초기화(잠금 키 입력 후) | 0x002C~0x002E, 0x400E, sys_command |

## 공통 규칙
- 상단 바: 축 상태와 알람 표시. 알람이 있으면 터치 시 6번으로 이동.
- 숫자 입력은 단위를 항상 함께 표시(예: "120.000 mm").
- 위험 동작(공장 초기화, 네트워크 초기화)은 확인 대화상자 2단계.
- 1축 모델은 Y축 요소를 숨긴다(모델 코드로 판별).
