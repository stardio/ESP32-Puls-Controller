# 알람·정지 원인 한글 문구표 (FR-033, D-074)

HMI 화면 데이터, PC 도구(`svtool alarm`), 매뉴얼이 같은 표를 쓴다. 코드는 interface-spec §5.8 기준이다.
기계가 읽는 표: 아래 표의 열 순서(코드 | 이름 | 화면 문구 | 원인 | 조치)를 바꾸지 않는다.

| 코드 | 이름 | 화면 문구 | 원인 | 조치 |
|---|---|---|---|---|
| 0x0000 | 없음 | 정상 | – | – |
| 0x0101 | E-ESTOP | 정지(STOP) 입력이 걸렸습니다 | STOP 스위치가 눌렸거나 STOP 배선이 끊겼습니다(NC 접점) | STOP 스위치와 J15(X)·J16(Y) STOP 단자 배선을 확인하고, STOP을 푼 뒤 START를 다시 누르세요 |
| 0x0201 | E-LIMP | + 방향 리밋에 걸렸습니다 | 축이 + 방향 끝에 도달했습니다 | − 방향으로 이동해 리밋에서 벗어나세요 |
| 0x0202 | E-LIMN | − 방향 리밋에 걸렸습니다 | 축이 − 방향 끝에 도달했습니다 | + 방향으로 이동해 리밋에서 벗어나세요 |
| 0x0203 | E-SWLP | + 방향 이동 범위를 넘습니다 | 목표 위치가 설정한 + 이동 한계보다 큽니다 | 목표 위치나 이동 한계 파라미터를 확인하세요 |
| 0x0204 | E-SWLN | − 방향 이동 범위를 넘습니다 | 목표 위치가 설정한 − 이동 한계보다 작습니다 | 목표 위치나 이동 한계 파라미터를 확인하세요 |
| 0x0301 | E-DRVALM | 서보 드라이브 알람 | 드라이브가 알람을 냈습니다 | 드라이브 화면의 알람 번호를 드라이브 매뉴얼에서 확인하고 원인을 없앤 뒤 알람 해제를 누르세요 |
| 0x0401 | E-COMMLOSS | 통신이 끊겼습니다 | 패널·PC와의 통신이 일정 시간 없었습니다 | 랜선(또는 RS-485 선)과 패널 통신 설정(IP 192.168.0.220, 포트 502)을 확인하고 알람 해제를 누르세요 |
| 0x0402 | E-JOGKEEP | 수동 운전이 멈췄습니다 | 버튼 유지 신호가 끊겨 안전을 위해 감속 정지했습니다 | 버튼을 다시 누르세요. 자주 생기면 통신 상태를 확인하세요 |
| 0x0501 | E-HOMEFAIL | 원점복귀에 실패했습니다 | 원점 센서를 찾지 못했거나 시간이 초과되었습니다 | 원점 센서 배선과 위치를 확인하고 알람 해제 후 다시 시도하세요 |
| 0x0502 | E-INPTO | 위치 완료 신호가 오지 않았습니다 | 드라이브의 위치 완료(INP) 신호가 시간 안에 오지 않았습니다 | 드라이브 게인·부하를 확인하거나 완료 대기 시간을 늘리세요 |
| 0x0601 | E-PE-UNDERRUN | 펄스 출력이 밀렸습니다 | 처리 지연으로 펄스 구간을 제때 갱신하지 못했습니다 | 속도·가감속을 낮추고 알람 해제를 누르세요. 반복되면 구입처에 문의하세요 |
| 0x0602 | E-PE-HW | 펄스 출력 장치 오류 | 출력한 펄스 수와 계수 값이 다릅니다 | 전원을 다시 켜세요. 반복되면 구입처에 문의하세요 |
| 0x0603 | E-PE-FAULTPATH | 정지 회로 점검 실패 | 하드웨어 정지 경로가 준비되지 않아 운전을 막았습니다(D-073) | 전원을 다시 켜세요. 반복되면 구입처에 문의하세요 |
| 0x0701 | E-PARAM | 설정값이 손상되어 기본값으로 바뀌었습니다 | 저장된 설정을 읽지 못했습니다 | 백업 파일로 복원하거나 첫 설정 마법사를 다시 진행하세요 |
| 0x0702 | E-NVM | 설정 저장에 실패했습니다 | 내부 저장소에 쓰지 못했습니다 | 다시 저장해 보세요. 반복되면 구입처에 문의하세요 |
| 0x0801 | E-WDT | 내부 감시로 재시작되었습니다 | 내부 오류로 장치가 자동 재시작되었습니다 | 운전 상태를 확인하세요. 반복되면 리셋 원인(0x002C)을 알려 주세요 |
| 0x0001 | 정상 완료 | 이동을 마쳤습니다 | – | – |
| 0x0002 | STOP 명령 | 정지 명령으로 멈췄습니다 | 패널 정지 버튼이 눌렸습니다 | – |
| 0x0003 | QUICK_STOP | 즉시 정지했습니다 | 즉시 정지 명령이 들어왔습니다 | – |
| 0x0004 | JOG 정지 | 수동 운전을 멈췄습니다 | – | – |

참고: 0x0603은 D-073(fault 경로 미바인딩 시 운전 금지)을 화면에 표시하기 위한 신규 코드다. 펌웨어가 다른 코드를 쓰면 펌웨어 값에 맞춘다.
