## 2. 다음 단계가 반드시 알아야 할 핵심 내용 (최대 10줄)
1. 추천 구성 C1: STM32F407VGT6 + 축당 하드웨어 타이머 2개(PWM + 32비트 계수) + LAN8720A + AM26C31(enable = 비상정지 게이트). MCU는 G3 실측 후 확정(ESP32 C2와 비교).
2. MCU 의존 코드는 HAL 6개(MOD-01~06)의 포트 구현(port_stm32f4 / port_esp32)에만 둔다. 상위 모듈(MOD-07~19)은 벤더 API·RTOS API를 직접 부르지 않는다.
3. 펄스 불변식: 큐에 넣은 펄스 수만큼만 출력하고, 다음 구간이 없으면 **추가 펄스 없이 정지**(언더런 = 정지 + 알람). 위치는 하드웨어 계수로만 계산한다(NFR-004).
4. 구간 방식: 구간 목표 1 ms [가정], 구간 완료 ISR(L1)에서 다음 구간 계산. L1 ISR은 RTOS API 금지, RAM 배치, 정수 연산만.
5. 레지스터 맵 단일 원본 `regmap.yaml`(MOD-20)에서 C 표·Python·한국어 문서·HMI 태그를 생성한다. 손으로 고친 표·주소 하드코딩 금지.
6. 모든 데이터는 홀딩 레지스터(FC03/06/16)로 접근 가능, 32비트 = 상위 워드 먼저, 축 기준 주소 0x1000×n, 1축 모델 축2 영역 = 예외 02.
7. 비상정지: 1차 하드웨어(MCU 비경유) + 2차 소프트웨어 래치. 기본 정책은 비상정지 후 위치 무효 + 원점복귀 요구(DC-08). 해제 후 자동 재기동 금지.
8. JOG는 명령 연결이 끊기거나 `jog_keepalive_ms` 동안 요청이 없으면 감속 정지(안전 측 [가정]).
9. 원가: 2축 모델이 BOM 확인값([가정] 환율)만으로 약 91,400원 → 9만원 초과 위험(R-07). 원가 결정(DC-12·13)으로 하드웨어가 바뀔 수 있으나 펌웨어 API는 영향이 없도록 설계했다.
10. 목표값이 "미확인"인 NFR(지터, 응답 시간 등)은 측정값을 기록·공개하는 방식으로 구현·시험한다.
