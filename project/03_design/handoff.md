## 2. 다음 단계가 반드시 알아야 할 핵심 내용 (최대 10줄)
1. 기준선: ESP32-P4(Waveshare ESP32-P4-ETH, ESP-IDF 5.5.3). 축1 = MCPWM 그룹 0 + PCNT(GPIO25 루프백), 축2 = 그룹 1 + PCNT 2번째 유닛. 이더넷 = 내장 EMAC + IP101(192.168.0.220:502, 유닛 1). W5500 제외.
2. 2축 자원 판단: **가능**(MCPWM 그룹 2개 확인, PCNT 복수 유닛). 그룹당 세부 수량·주기 레지스터 폭·CW/CCW 자원·고장 입력·GPIO 여유는 **미확인** → TFW-02·04 probe와 PS-27로 확정.
3. 정지 불변식: 위치 = 출력 핀 PCNT 계수. 목표 도달 시 주파수 ≤ f_stop_max(임시 5,000 pps [가정], T-08로 확정). 초과 계수 = `E-PE-HW`.
4. 기존 코드 위험 3건을 TFW에서 먼저 확인: 주파수 양자화(요청보다 높은 출력 가능, R-15), PCNT ISR IRAM 비안전 + 쓰기마다 NVS 저장(R-16), 10 ms 태스크 속도 갱신(R-19 관련).
5. 비상정지 입력 = **GPIO19**(D-027). 커밋 2135568 코드는 GPIO18 → 복사 후 수정하고 부팅 시 레벨 로그로 배선 확인(R-14).
6. 레지스터 맵: HR 0x0000~0x001F·코일 0~7·DI 0~7 = 기존 맵 그대로(레거시 창, 기존 MT8051iP 무수정 운전). 신규는 0x0020~(시스템), 0x1000×n(축). 32비트 **하위 워드 먼저**. 시험 창 0x7000~0x70FF는 TFW 전용.
7. 시험 펌웨어 범위 밖(④): 원점·리밋·알람·파라미터 체계·RTU 슬레이브·펌웨어 갱신·regmap 생성기·신규 HMI 화면.
8. 기존 실적으로 대체(D-028): T-01(단축 최고 주파수), T-02(단축 핀 계수 정확도), T-14의 1축 부분. 드라이브 모델·배선·측정 기록은 미확인 → 사용자 보완 요청.
9. 모듈 대응: 재사용 0, 수정 후 재사용 13, 신규 12(architecture §3.2). 래더 코드는 쓰지 않는다.
10. 원가: v0.2 집계(STM32 기준)는 무효. ESP32-P4 탑재 형태(보드/모듈/칩) 가격은 parts-selector 재조사(PS-23·28) 후 DC-13으로 판정.
