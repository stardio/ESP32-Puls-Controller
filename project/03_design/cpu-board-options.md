**결정(2026-11-04, D-086): 사용자가 D(완성 보드 구매 유지)를 선택했다. 권고 A1은 채택되지 않았다. USB 핀 충돌(R4)은 D-087로 해소했다(X 펄스 22, RS-485 TX 14).**

변경 이력: v0.1 → v0.2 architect 리뷰(reviews/cpu-board-options-review-1.md, 판정 "조건부 유지") 반영. C-01 해소(GPIO54 유지 확인), M-01~M-08·m-01~m-09 반영.

> **목적.** Waveshare ESP32-P4-ETH 보드(F1)에 의존하지 않도록 필요한 기능만 넣은 CPU 보드를 직접 만드는 방안을 비교한다. G3(MCU 기준선 확정, D-024)에 올릴 근거 자료다.
> **결정 아님.** MCU 형태와 개발 투자는 사용자 결정이다(CLAUDE.md 규칙 9). 이 문서는 권고안까지만 낸다.
> **가격 한계.** 가격은 웹 검색 결과 요약 값이며 원문 대조 전이다. 환율 [가정] 1 USD = 1,400원(bom-draft §5와 같음). 수량 구간은 표마다 적었다.

손익분기 [산술]: A1이 D보다 유리해지는 연간 수량 N ≥ NRE ÷ (대당 절감액). 예: NRE 300만원 [가정], 대당 절감 5,000원 [가정](확인분 7,500~10,400원에서 미확인 부품을 뺀 값)이면 N ≥ 600대다. NRE와 대당 절감 모두 [가정]이므로 이 수는 판단 예시일 뿐이다. 수량이 이보다 적으면 **D(리비전 명시 구매 + 재고 확보)**가 돈으로는 유리하다. 다만 D는 리비전 위험(W4)을 그대로 안는다.

|---|---|---|
| PCB | CPU 보드만 4층(작음), 캐리어는 2층 [가정] | 큰 보드 전체가 4층 |
| 커넥터 | 2×20 핀헤더 한 쌍 추가(원가 **미확인**) | 없음 |
| 모델 구성 | 1축/2축, TCP/RTU 캐리어 여러 종에 같은 CPU 보드 사용 | 모델마다 4층 보드 |
| 예비 경로 | F1 보드를 그대로 꽂을 수 있다(헤더 호환일 때) | 없음 |
| 위험 | 헤더 전기·기구 배치를 F1과 맞춰야 한다. 진동·접촉 신뢰성 [가정] | 첫 제작에서 CPU 부분 실수가 나면 보드 전체 재제작 |

**헤더 신호 규칙 [권고]:** 헤더 = 전원(5 V, 3.3 V, GND) + D-069의 20개 GPIO + 예비 GPIO만 둔다. RMII·50 MHz 기준 클록·MDIO·PHY 리셋·플래시·크리스털·USB는 **CPU 보드 내부**에 둔다. 헤더에는 저속 신호만 지나간다.

**호환 확인 두 단계:** ① 전기 호환: 캐리어 회로도 J1/J2(reference/2axis-schematic.pdf)의 넷으로 사용 핀의 헤더 위치와 3.3 V·5 V 핀을 지금 확인할 수 있다. ② 기구 호환: 외형, 고정 구멍, 커넥터 높이, RJ45·USB 위치(외함 개구부)는 F1 도면이 필요하다(PS-27).

권고: **A1.** 첫 자체 설계에서 CPU 부분의 위험을 작은 보드에 가두고, 지금 캐리어와 벤치 환경(D-085)을 그대로 쓸 수 있다. 양산 수량이 커지면 A2로 합치는 것을 다시 검토한다.
