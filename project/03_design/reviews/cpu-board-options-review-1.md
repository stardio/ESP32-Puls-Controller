## 1. 요약

**판정: 조건부 유지.**

A1(P4 v3.x 칩을 직접 실장한 분리형 CPU 보드, F1 헤더 호환) 권고의 방향은 타당하다. 근거는 세 가지다. 같은 칩 계열이라 D-071의 HAL 분리와 MCPWM fault 경로(D-070·D-073)를 그대로 이어 쓸 수 있다. 무선이 없다(R7). 공급 보장 기간이 가장 길다(W1, 원문 대조 전). 분리형으로 첫 4층·QFN 설계의 위험 범위를 좁히는 판단도 맞다.

다만 G3 근거 자료로 쓰려면 아래 조건을 먼저 채워야 한다.

1. **v3.x에서 사라지는 핀(W3의 "핀 54")이 캐리어가 쓰는 GPIO54(DI1 START 축1)와 같은지 확인해야 한다(C-01).** 같다면 "펌웨어는 리비전 설정만 바꾸면 된다"와 "헤더 호환"이라는 두 전제가 함께 무너진다.
2. 안전 요구 중 부팅·리셋 시 펄스 금지(GPIO33 풀다운, /G 비활성), 리셋 시 GPIO 기본 상태·스트래핑 핀, CPU 보드 전원(캐리어 3.3 V 부하 포함), 이더넷 절연 경계가 R1~R8에 없다(M-01~M-03).
3. §6 순서는 G3를 A1 시제품 실측 뒤로 미룬다. 이것은 D-068(G3 판정 방법)·D-024와 맞지 않고, 평가 보드로는 T-07을 캐리어 기준으로 실측할 수 없다(M-05·M-06).
4. 사업 판단인 DC-30·DC-32에 필요한 개발비·일정(NRE)이 비교에 없다(M-07).

## 3. 확인 항목별 결과

| 확인 항목 | 결과 |
|---|---|
| 1. R1~R8과 기준선·결정의 정합, 빠진 요구 | R1(D-070·D-073의 MCPWM fault 1차 차단)과 R2(D-078)는 결정과 맞다. 빠진 것은 부팅·리셋 중 펄스 금지(M-01), 전원(M-02), 절연 경계·포트 보호(M-03), USB 구현(M-08), 생산·식별(m-07)이다. STOP 하드웨어 차단의 외부 AND 게이트(기준선 §3, §4 항목 3)는 캐리어 쪽이라 CPU 보드 요구에서 빠져도 된다. 다만 기준선 §3 문구는 D-070과 어긋난다(이슈 제기 2) |
| 2. A1 권고 논리, 사실 오류·근거 없는 수치 | 논리는 타당하다(조건부). 사실 확인이 필요한 것은 C-01이다. 수치 오류는 m-01(21 → 20)이다. 표시가 빠진 것은 m-03이다. 원가 산술은 맞다 |
| 3. 분리형·헤더 호환의 빠진 기술 위험 | 헤더를 지나는 신호 범위 원칙(RMII 등 고속 신호를 헤더에 두지 않음), 기구 호환, 전원 공급 경로, 리셋·스트래핑, USB 핀 충돌(M-01·M-02·M-04·M-08) |
| 4. §6 순서·§7 결정 후보와 G3 규칙 | §6은 G3를 시제품 뒤로 미루고 D-068과 맞지 않는다(M-05·M-06). §7의 결정 주체 구분은 규칙 9와 맞다. DC-30·DC-32는 사용자, DC-31·DC-34는 권고 기본값, DC-33은 사용자 확인이다. 시제품 제작 투자를 다룰 결정 후보가 없다(M-06). D-036 변경이라는 점이 드러나 있지 않다(m-08) |
