### 2.3 이더넷 — 기준선: 내장 EMAC + IP101 (D-024, D-027)

- ESP32-P4는 RMII 이더넷 MAC을 내장하고[S5], ESP-IDF는 내장 EMAC 대상에 ESP32-P4를 포함한다[S3]. Waveshare ESP32-P4-ETH는 EMAC + IP101 PHY(RMII) 구성이다[S14]. 기존 코드는 `esp_eth_mac_new_esp32()` + `esp_eth_phy_new_ip101()`, PHY 주소 1, PHY 리셋 GPIO51, 고정 IP 192.168.0.220/24로 동작한다[E2].
- 기존 코드는 W5500(SPI) 2차 인터페이스(192.168.0.230)도 초기화하며 실패 시 무시한다[E2]. HMI는 IP101로 연결한다(D-027). **제품 기준선에서 W5500은 제외**한다(BOM·핀 절약). 2포트 필요 여부(Q26)가 "필요"로 바뀌면 W5500 코드를 재사용할 수 있다.
- 기존 TCP 서버는 연결마다 태스크 1개(우선순위 6, 스택 4 KB), listen backlog 4, 수신 타임아웃 5 s[E2]. 접속 수 상한 강제는 없다 → MOD-15에서 `max_clients` 적용.
- 이더넷 포트 절연 내압은 보드 RJ45 데이터시트 미확인(R-06, PS-24).

### 2.4 펄스 생성 — 기준선: MCPWM + PCNT (기존 1축 방식 확장)

기존 1축 동작 원리[E1][E2]:
1. MCPWM 타이머(그룹 0, 업 카운트, 해상도 2 MHz) → 오퍼레이터 → 비교기(TEZ에서 비교값 갱신) → 제너레이터(TEZ에서 High, 비교 일치에서 Low). 주기 = 해상도 / 주파수, 비교값 = 주기 / 2.
2. PCNT 유닛 1개가 같은 GPIO의 상승 엣지를 계수. 상한 30,000에서 감시점(watch point) 인터럽트로 소프트웨어 누적, 목표값 나머지(target mod 30,000)에 두 번째 감시점. 목표 도달 ISR(IRAM)에서 제너레이터를 Low로 강제(force level)해 정지.
3. 가감속: 운동 태스크(우선순위 7)가 10 ms마다 현재 계수값으로 사다리꼴/삼각형 프로파일 주파수를 계산(double, sqrt)해 타이머 주기를 바꾼다. 시작 주파수 = min(5,000 Hz, 설정 속도), 감속 끝 주파수도 시작 주파수다.

이 방식에서 정지 정확도가 성립하는 이유와 조건(v0.2의 P3 위험 판단 개정):
- 목표 도달 정지는 ISR 응답에 의존한다. 그러나 감속 끝 주파수가 시작 주파수(≤ 5 kHz, 주기 ≥ 200 µs [산술])이므로 ISR 지연 허용치는 5 µs가 아니라 약 200 µs다. 1 MHz 운전에서도 목표 펄스 수가 정확히 일치했다는 1축 기록이 있다(1,000,000 펄스, 내부 루프백 계수)[E5].
- 따라서 제품 불변식을 **"목표 도달 시점의 출력 주파수 ≤ f_stop_max, f_stop_max = 1 / (목표 정지 ISR 최악 지연 × 여유계수)"**로 정한다. 최악 지연은 TCP 부하·플래시 쓰기 중 실측(T-08)으로 정한다. `start_speed` 상한은 f_stop_max로 제한한다.
- 즉시 정지(QUICK, 리밋, 비상정지)는 목표 수와 무관하다. PCNT가 출력 핀을 직접 계수하므로 정지 후 위치는 실제 핀 출력과 일치한다.

### 2.6 비상정지 경로 (v0.3)

```
 비상정지 입력(24 V, 절연) ──┬──► [1차] 외부 라인 드라이버 enable 차단 (MCU 비경유, 회로)
                             ├──► [1.5차] GPIO19 → MCPWM 그룹 0·1 고장(fault) 입력 → 제너레이터 브레이크 (MCU 내 하드웨어, 미확인)
                             └──► [2차] GPIO19 엣지 인터럽트 → 전 축 force level·타이머 정지 → 래치 → 해제 명령 전 기동 거부
```

- 1.5차 경로: ESP-IDF는 ESP32-P4에서 MCPWM GPIO 고장 입력 수 매크로(`SOC_MCPWM_GPIO_FAULTS_PER_GROUP`)를 정의한다[S10](값 미확인). 고장 입력으로 오퍼레이터 브레이크를 걸면 CPU·ISR 지연과 무관하게 핀 출력이 멈춘다 [가정: P4 동작은 TFW-04로 확인]. GPIO 하나를 두 그룹의 고장 입력에 동시에 연결할 수 있는지는 미확인(GPIO 매트릭스 입력 라우팅).
- 위치 일관성: 1.5차·2차 경로는 핀 앞에서 멈추므로 PCNT 계수 = 핀 출력이다. 1차 외부 게이트는 핀 뒤에서 끊으므로, 1차가 먼저 끊고 1.5차가 늦게 멈춘 사이의 펄스는 계수되었지만 드라이브에 가지 않았을 수 있다. 그 차이(시간 × 주파수)는 T-07에서 측정한다. 기본 정책은 v0.2대로 **비상정지 후 위치 무효 + 원점복귀 요구**, T-07에서 차이 0이 확인되면 위치 유지 정책을 선택지로 연다(DC-08).
- STOP 입력 극성: 기존은 Active-LOW(풀업, 접점 닫힘 = 정지)[E5]. 이는 단선 시 정지하지 않는 방향이다. 제품 비상정지는 NC 접점·전류 상실 = 정지 [가정]이므로 극성을 반대로 해야 한다 → DC-17.
- 고지: 보조 정지이며 안전 회로를 대체하지 않는다(NFR-020).

### 2.7 전원

- 24 VDC ±10% [가정] 입력 보호(역접속·TVS·퓨즈)는 v0.2 유지.
- Waveshare ESP32-P4-ETH의 전원 입력 방식(USB 5 V, PoE 모듈 헤더 등)·소비 전류는 미확인[S14] → PS-25. 24 V → 5 V(또는 보드 요구 전압) 강압 후보는 v0.2의 TPS54331(입력 최대 28 V)[P14] 재검토.
- 절연 전원(DC-05): 기존 RS-485 J12에 "절연 5 V" 핀이 있다[E10 RS485 문서]. 해당 절연 전원이 보드 자체인지 추가 보드인지 미확인.

### 3.1 모듈 분해와 HAL 추상화 (v0.3)

- 구조는 v0.2(MOD-01~25)를 유지한다. 1차 포트는 **port_esp32p4(ESP-IDF 5.5.3, FreeRTOS)**[E8]. port_stm32f4는 §4.5 전환 시에만 만든다(DC-14).
- 핵심 불변식(v0.3 개정): (1) 위치는 출력 핀 PCNT 계수로만 계산한다. (2) 목표 도달 시 출력 주파수 ≤ f_stop_max. (3) 목표 초과 펄스가 계수되면 `E-PE-HW`(기존 "펄스 불일치" 결과 3과 같은 의미)[E2]. (4) 방향은 정지 중에만 바꾼다. v0.2의 "구간 큐 언더런 = 정지"는 MCPWM 방식에서 "속도 갱신 지연 감시"로 바뀐다(MOD-07 v0.2).
- 레지스터 맵 단일 원본 `regmap.yaml`(MOD-20)은 유지하되, 기존 servo1axis 맵을 "레거시 창"으로 포함한다(interface-spec §5.0).

### 4.5 STM32F407 전환 조건 (DC-01)

ESP32-P4 기준선을 다음 중 하나가 성립할 때 STM32F407(C1)로 바꾼다. 먼저 ESP32-P4 안의 대안(해상도 조정, ETM 정지, 코어 배치, RMT)을 시도한 뒤에도 해소되지 않을 때만 적용한다.

## 5. 원가(잠정 약 9만원) 평가 — v0.3

- v0.2 §5의 BOM 집계(1축 약 71,500원, 2축 약 91,400원, [가정] 환율)는 MCU = STM32F407, ETH = LAN8720A + HR911105A 기준이므로 **v0.3 기준선 원가로 쓸 수 없다**. 하우징·단자대(GBP 27.94/37.90) 등 MCU와 무관한 항목은 유효하다.
- ESP32-P4 탑재 형태별 원가 구조(정성, 가격 미확인):

| 형태 | 포함 범위 | 원가 영향(정성) | 비고 |
|---|---|---|---|
| F1 Waveshare 보드 그대로 + 캐리어 PCB | MCU·플래시·PSRAM·IP101·RJ45·보드 전원 | 보드 가격이 그대로 원가. 개발 위험 최소(기존 실적 그대로) | 양산 공급·온도 등급·치수 미확인 |

| F3 ESP32-P4 칩 + 자체 PCB | 칩·플래시·PHY·RJ45·전원 | 부품가 최소 가능, 설계·검증 비용 최대 | 고속 RMII·전원 설계 필요 |

- 가격은 parts-selector 재조사(§7 PS-23·28) 결과로 채운다. 이 문서는 가격을 만들지 않는다. 판정 기준은 DC-13.

## 8. 추천안과 결정 후보

### 8.1 추천안

**C5: ESP32-P4(Waveshare ESP32-P4-ETH 기준) + 축당 MCPWM 그룹 1개·PCNT 유닛 1개(출력 핀 루프백 계수, 감시점 목표 정지, f_stop_max 불변식) + 1 ms [가정] 하드웨어 타이머 속도 갱신 + 내장 EMAC·IP101 1포트 + 비상정지 3단 경로(외부 게이트·MCPWM 고장 브레이크·소프트웨어 래치) + 기존 HMI 맵 호환 레거시 창.** STM32F407은 §4.5 조건 성립 시 전환하는 대안.
